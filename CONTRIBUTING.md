# Contributing to WorkerInformedAI

Thank you for your interest in contributing to **WorkerInformedAI**! This project aims to advance meaningful worker participation in AI and workplace technology through open, practical resources.

## Our Values

- Respect for workers and their lived experience
- Commitment to health, safety, and "do no harm"
- Transparency and collaboration
- Inclusive and non-retaliatory participation

## Ways to Contribute

### 1. Report Issues or Suggest Improvements
- Open an issue for bugs, unclear language, or missing features
- Suggest new adaptations (e.g., manufacturing, healthcare, logistics)

### 2. Submit Adaptations or New Content
- Sector-specific versions of the WIPP clause
- Templates (impact assessments, workshop agendas, joint committee charters)
- Translations
- Case studies or implementation examples

### 3. Technical Contributions
- Prototype tools or compliance configurators
- Integration examples (GitHub Actions, Jira, RAG systems)
- Documentation improvements

### 4. Review and Feedback
- Review pull requests
- Test clause language in real-world contexts (with appropriate permissions)

## Contribution Process

1. **Fork** the repository
2. Create a new branch (`git checkout -b feature/amazing-improvement`)
3. Make your changes
4. Ensure your contribution aligns with the project values
5. Submit a **Pull Request** with a clear description

## Code of Conduct

We follow the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Harassment, discrimination, or disrespectful behavior will not be tolerated.

## Questions?

- Open an issue labeled `question`
- Or reach out via GitHub Discussions (if enabled)

**Together we can build better, safer, and more equitable workplace technology.**
