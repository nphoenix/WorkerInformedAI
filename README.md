# WorkerInformedAI

**Meaningful worker participation in AI and workplace technology.**

This repository provides open-source resources to embed worker-informed participation into the design, procurement, and governance of AI/software systems — especially those affecting health, safety, and working conditions.

## Core Resource: Worker-Informed Participation Protocol (WIPP)

WIPP is a practical, adaptable protocol that moves beyond consultation to **active co-participation**.

[Read the full WIPP Boilerplate Clause →](WIPP-CLAUSE.md)

## Key Features
- Ready-to-adapt contract / policy language
- Templates for joint impact assessments
- Guidance for co-design workshops
- Pathways to compliance verification tools (SBIR in progress)

## Why This Matters
Workers closest to the work have unique insight into real-world risks and harms. WIPP helps organizations meet NIST AI RMF, DOL AI Principles, and union best practices while reducing deployment risks.
